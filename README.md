# Aether FM

Tactile web and mobile radio station player built with React, Vite, and Capacitor.
Features continuous live audio streaming across diverse genres and frequency bands.
Emulates analog receiver tuning with real-time audio visualization and quick presets.

## Scripts
- `npm run dev`: Start local Vite development server
- `npm run build`: Compile production client bundle
- `npm run lint`: Run ESLint checks
- `npx cap sync android`: Sync web assets to Capacitor Android project
