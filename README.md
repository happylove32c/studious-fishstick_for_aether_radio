# Aether FM

Aether FM is a web radio station player with a tactile hardware-inspired interface.
It organizes online live audio transmissions across diverse genres and frequency bands.
The player supports native audio streams as well as adaptive HLS live broadcast feeds.
Users can discover stations, browse curated genres, and tune into high-fidelity streams.
Features include a spectrogram equalizer, custom frequency dial, and favorite presets.
Station metadata is cached locally for fast startup with background freshness updates.
The responsive interface adapts seamlessly from compact mobile viewports to wide screens.
Built with React 19, Vite, Tailwind CSS, and Lucide icons for crisp typography and design.
Run `npm run dev` to start the local development server or `npm run build` to bundle.
Enjoy continuous, low-latency live radio broadcasts with precise audio controls.
